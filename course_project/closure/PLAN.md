# 最后一轮有限收尾计划

研究问题：原有参数约束阻止恶意收款人修改后，Agent为何无法完成仍被原请求支持的普通任务部分？

先对全部已有租金轨迹分类，再只实现一个候选：Agent与语义检查器共享同一授权政策。既有两条硬约束保持不变，不改原生工具、不自动改写调用参数、不添加额外复核、不模拟用户确认，不提供标准答案或隐藏评分。候选同时澄清最小改动原则及可分离操作，不能将结果单独归因于某一句提示或某一个组件。

固定比较为旧参数约束和新候选：租金题正常+原有4种攻击各3次，共30次；地址、密码、明确收款账户3个正常控制各3次，共18次。合计48次；一轮、一个候选，局部预算5元，累计150元，18:00后的非高峰时段运行。没有付费提示开发。

原生评分、原补充严格评分、保留未指定日期/周期后的严格安全完成分别呈现；等待确认算未完成。候选、任务和攻击都是已观察数据基础上的事后收尾，不称为留出任务或普遍可靠性验证。

成功、部分成功或失败均可结项：若安全完成提高，给出局部支持；若仍失败，逐轨迹说明停在何处；若出现额外状态修改或正常任务损失，披露并拒绝夸大。完成这一轮即停止研究扩张。技术问题允许在原预算内恢复同一固定调度，不能因质量结果不理想重试。

其他范围边界——跨模型、未见自适应攻击、通用授权和原论文总体数字——不转为本轮新增实验。原报告/PPT/讲稿保持不动，先完成研究收束。

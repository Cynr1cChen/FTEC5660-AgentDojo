## Evidence and offline reproduction

From repository root, after installing `course_project/requirements.lock.txt`:

```bash
.venv/bin/python -m course_project.evidence verify
.venv/bin/python -m course_project.extension_review.evidence verify
.venv/bin/python -m course_project.round2.evidence verify
```

The three commands verify three separate, hash-indexed archives. They restore archived actor source and replay recorded responses with outgoing sockets blocked. They do not generate new model answers. `fresh_environment.json` describes the separate fresh virtual-environment validation using a local offline package cache; it does not claim another operating system or a fresh network download.

Paid historical protocols are immutable research records, not an invitation to retry failures. The round2 runner defaults to off-peak starts and enforces local/cumulative conservative limits. The one peak-period continuation has explicit user authorization, a10CNY local limit and150CNY cumulative limit. Future paid sampling needs an applicable budget and schedule authorization.
